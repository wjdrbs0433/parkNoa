# About 내용 수정

`site-content.xlsx`의 **About** 시트에서는 B열 `입력 내용`을 수정하세요. 이름, 사진, 각 구역의 제목처럼 한 번만 쓰는 값이 있습니다.

새 문단이나 목록 항목은 **About 목록** 시트에 행을 추가합니다. A열 `구역`을 드롭다운에서 고르고, 같은 구역의 기존 행을 참고해 필요한 열을 채우세요. 번호나 항목 키를 만들 필요는 없습니다. 같은 구역 안에서는 엑셀의 행 순서대로 표시됩니다.

| 구역 | 입력할 열 |
| --- | --- |
| 소개 문단 | 내용 |
| 연구 분야 | 내용 |
| 학력 | 기간, 제목·학위, 학교·설명, 필요하면 이미지 경로·설명 |
| 심사 저널 | 내용 |
| 활동 | 기간, 제목·학위, 내용 |

예를 들어 연구 분야를 하나 늘리려면 기존 `연구 분야` 행 아래에 새 행을 넣고 A열에서 `연구 분야`를 선택한 뒤 D열 `내용`을 입력합니다. 활동 한 건에 문장을 두 개 넣으려면 같은 기간과 제목으로 행을 연속해서 추가합니다.

- 사진은 `img/` 폴더에 넣고 **About** 시트의 `프로필 사진` 행에 `img/파일명.png`처럼 적습니다.
- 저장 후 GitHub에 올리면 배포 작업이 엑셀을 읽어 About, Publication, Abstract, Gallery 페이지 데이터를 생성합니다. GitHub 저장소의 Pages 설정에서 배포 원본을 **GitHub Actions**로 지정해야 합니다.
- 현재는 About, Publication, Abstract, Gallery 시트가 연결되어 있습니다.

## 로컬에서 확인

로컬 미리보기 터미널에서 `Site local preview` 작업을 실행하세요. 열린 상태에서 엑셀 셀을 수정하고 Enter, Ctrl+S로 저장한 뒤 브라우저를 새로고침하세요. 미리보기 서버가 엑셀 변경을 확인하고 About, Publication, Abstract, Gallery의 데이터 JS를 다시 만들어 최신 내용을 표시합니다. 터미널에 오류가 나오면 엑셀 내용을 수정해 다시 저장하세요. 미리보기 터미널이 실행 중이 아니라면 프로젝트 폴더에서 `python scripts/build-about.py`, `python scripts/build-publication.py`, `python scripts/build-abstract.py`, `python scripts/build-gallery.py`를 직접 실행해야 합니다. 현재 PC의 PowerShell에서는 `& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" scripts/preview-content.py`로 미리보기 서버를 실행할 수도 있습니다. 다른 Python을 사용하며 `openpyxl`이 없다면 `python -m pip install openpyxl==3.1.5`를 먼저 실행하세요.

## Publication 내용 수정

**Publication** 시트의 한 행이 논문 한 건입니다. A열 `번호`, B열 `저자·연도`, C열 `논문 제목`(파란 글자), D열 `제목 뒤 내용`을 입력하세요. 기존 제목의 외부 링크를 유지하기 위해 E열 `논문 링크 (선택)`을 추가했습니다. 링크가 없다면 E열을 비워두세요. D열은 제목 바로 뒤에 붙는 문구이므로 마침표가 필요하면 `. Journal Name 123:456.`처럼 마침표부터 입력합니다. 행을 추가하거나 삭제하면 페이지의 논문 건수가 자동으로 바뀌고 번호 큰 순서로 표시됩니다.

## Abstract 내용 수정

**Abstract** 시트의 한 행이 초록 한 건입니다. A열 `번호`, B열 `저자·연도`, C열 `초록 제목`(파란 글자), D열 `제목 뒤 내용`을 입력하세요. D열은 제목 뒤의 마침표부터 시작해 `. Proceedings of ...`처럼 입력합니다. D열 내용은 페이지에서 이탤릭체로 표시됩니다. 행을 추가하거나 삭제하면 페이지의 발표 건수가 바뀌고 번호 큰 순서로 표시됩니다.

## Gallery 내용 수정

**Gallery** 시트의 한 행이 사진 한 장입니다. `img/` 폴더에 사진을 넣고 A열에는 확장자를 뺀 파일명, B열에는 `jpg`, `jpeg`, `png`, `webp` 중 파일형식을 적습니다. C열 `년도`, D열 `월`(1~12), E열 `순서`를 숫자로 입력하세요. 같은 연도와 월에서는 순서가 중복되면 안 됩니다. F열 `그리드 표시`가 `예`인 사진만 선택한 연도의 사진 목록에 나타납니다. G열 `사진 설명 (선택)`을 비워두면 `Feb 2025`처럼 연월을 표시합니다. 마지막 H열 `캐러셀 순서 (1~3)`에는 상단 슬라이드로 사용할 사진 세 장에 각각 `1`, `2`, `3`을 입력하세요. 다른 사진의 H열은 비워둡니다. 캐러셀은 연도 선택과 관계없이 이 세 장을 계속 보여줍니다.

기존 사진 중 목록에서 제외했던 파일은 F열을 `아니요`로 두었습니다. 필요하면 `예`로 바꾸세요. 새 행은 F열을 비우면 목록에 표시됩니다. 갤러리 목록은 최신 연도가 기본 선택되며, 해당 연도 안에서 월과 순서가 큰 사진부터 표시됩니다. **A열 파일명과 B열 형식은 `img/` 폴더의 실제 파일과 정확히 같아야 합니다.** 예를 들어 `gallery01_Dec_2025.png`가 있다면 A열은 `gallery01_Dec_2025`, B열은 `png`입니다. 엑셀에서 `png`를 `jpg`로 바꿔도 실제 사진이 JPG로 변환되지는 않습니다. 파일이 없으면 그 사진만 제외하고 터미널에 안내합니다. 새 사진은 먼저 `img/` 폴더에 넣고 엑셀에 행을 추가하세요. 저장 후 로컬 페이지를 새로고침하면 작은 WebP 미리보기 이미지와 갤러리 목록이 생성됩니다. 원본 사진은 확대해서 열 때만 내려받습니다. GitHub 배포 시에도 같은 생성 작업이 실행됩니다.
